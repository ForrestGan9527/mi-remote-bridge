手机语音需要写入 macOS 虚拟声卡，项目不包含驱动。推荐安装免费的 BlackHole 2ch；也可以使用 MiRemoteV 2ch 或 SayAll。

方式一 · Homebrew

brew install blackhole-2ch

方式二 · 官方安装包：点击下方「下载 BlackHole 2ch」。

安装后重启电脑，或执行 sudo killall coreaudiod。然后点击「重新检测」，在「虚拟麦克风」下拉框选择 BlackHole 2ch，并在输入法 / 会议软件中把麦克风设为它。

语音输入工具 · 推荐安装豆包输入法

虚拟声卡负责把手机语音送进 Mac；还需要一个语音输入工具把声音转成文字。推荐豆包输入法，它支持按住 Fn 进行语音输入。

方式一 · Homebrew

brew install --cask doubaoime

方式二 · 官方下载：点击下方「下载豆包输入法」。

安装后：在系统设置 → 键盘 → 文本输入 → 输入法中启用豆包输入法；把豆包的语音快捷键设为 Fn，麦克风设为已选择的虚拟声卡；电脑端「语音触发」也选择 Fn。然后按住手机语音键即可。

下载豆包输入法

豆包输入法为第三方软件；也可以使用 Typeless 等其它支持虚拟麦克风和 Fn 触发的语音输入工具。
